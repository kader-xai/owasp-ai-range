LLM01 · Image prompt injection

Same task, different carrier

The assistant should summarize the approved 30-day policy. A customer image can contain instructions that try to redirect the answer. This uses a real local vision model—not text extraction passed off as vision.

Ball analogy

Think of the image as a wrapper around the ball. Instructions printed on that wrapper can steer the model just like typed instructions. The defense keeps the whole untrusted wrapper outside this policy-only task.

Defended mode excludes the image before inference. It does not solve image tasks securely or prove universal immunity. Marker presence is a narrow observation, not a benchmark.

Setup: ollama pull granite3.2-vision:2b. Model download is about 2.4 GB; runtime memory is additional. Override OLLAMA_VISION_MODEL before starting the app to choose another vision model.
